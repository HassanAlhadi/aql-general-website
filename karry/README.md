# مِقوَد — لوحة قيادة Karry / Alora

صفحة محمية على `/karry` تعرض حالة الشركة من أودو **مباشرةً**، بصلاحية **قراءة فقط**.

## نموذج الأمان

| الطبقة | الحماية |
|---|---|
| **الصفحة الثابتة** | لا تحتوي **أي** بيانات شركة — هيكل فارغ فقط. المستودع عام، فلا شيء فيه يُسرّب. |
| **البيانات** | تأتي من `/api/data` فقط، وترفض بـ 401 بلا جلسة صالحة. |
| **مفتاح أودو** | متغيّر بيئة في Vercel — لا يصل المتصفح إطلاقاً، ولا يدخل المستودع. |
| **كلمة المرور** | مخزّنة كـ **scrypt hash** في متغيّر بيئة. لا نص صريح في أي مكان. |
| **الجلسة** | كوكي موقّع بـ HMAC · `HttpOnly` · `Secure` · `SameSite=Strict` · ينتهي بعد ٨ ساعات. |
| **الكتابة على أودو** | **مستحيلة** — `api/_lib.js` يرفض أي method خارج القراءة (`READ_ONLY`). |
| **الفهرسة** | `noindex` + `robots.txt` + `Cache-Control: no-store`. |

### ما لا تحميه هذه الطبقة — بصراحة
- **لا يوجد عدّاد محاولات موثوق.** دوال Vercel بلا حالة مشتركة، فلا مخزن للمحاولات.
  يوجد تأخير ثابت ٧٠٠ms لكل محاولة + بطء scrypt، وهذا يبطئ التخمين لكن لا يوقفه.
  ➜ **الحاجز الحقيقي هو قوة كلمة المرور.** هذا سبب رفض السكربت للكلمات الضعيفة.
- **حماية Vercel على مستوى الحافة (Password Protection) غير متاحة** — ميزة Pro،
  والحساب على خطة Hobby. لو تُرقّيت لاحقاً، فعّلها فوق هذه الطبقة لا بدلاً منها.

## الإعداد — مرة واحدة

### ١. ولّد كلمة المرور وسرّ الجلسة (على جهازك، لا هنا)
```bash
node scripts/make-hash.mjs
```
يرفض الكلمات الضعيفة ويطبع سطرين: الـhash وسرّ الجلسة.
**كلمة المرور نفسها لا تُطبع ولا تُحفظ ولا تُرسل.**

### ٢. أضف متغيرات البيئة في Vercel
Project `aql-general-website` ← Settings ← Environment Variables ← أضفها لـ **Production**:

| المتغيّر | القيمة |
|---|---|
| `MIQWAD_USER` | اسم المستخدم |
| `MIQWAD_PASS_HASH` | السطر `scrypt$...` من الخطوة ١ |
| `MIQWAD_SECRET` | السطر العشوائي الثاني من الخطوة ١ |
| `ODOO_URL` | `https://karry-live.odoo.com` |
| `ODOO_DB` | اسم قاعدة البيانات |
| `ODOO_USER` | بريد المستخدم في أودو |
| `ODOO_API_KEY` | مفتاح API — **قراءة فقط** |

⚠️ علّم `MIQWAD_PASS_HASH` و `MIQWAD_SECRET` و `ODOO_API_KEY` كـ **Sensitive**.

### ٣. أعد النشر
أي push يُطلق نشراً جديداً. المتغيرات تُقرأ عند التشغيل.

## الملفات
```
karry/index.html     الهيكل + شاشة الدخول (بلا بيانات)
karry/app.js         الواجهة — تسحب من /api/data وترسم
api/_lib.js          الجلسة + عميل أودو (حاجز القراءة فقط)
api/login.js         المصادقة
api/logout.js        إنهاء الجلسة
api/data.js          تجميع بيانات أودو — يتطلب جلسة
scripts/make-hash.mjs مولّد الـhash (يُشغَّل محلياً)
```

## عند تغيّر اسم قاعدة أودو
رقم البناء في `plementus-karry-master-<رقم>` يتغيّر مع كل نشر من Plementus.
إن توقفت اللوحة: استخرج الاسم الجديد من أودو (الإعدادات ← Activate developer mode)
وحدّث `ODOO_DB` في Vercel.
